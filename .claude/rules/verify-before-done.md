# Verify before you say "done"

Loaded every session. This is the single most important habit in the system.

**Something is done when it has been shown to work, not when it has been
written.** Code that "should work" has not been tested. A file that was
"saved" might be in the wrong folder. A skill that was "created" might never
fire.

## How to apply

- **Run it.** If you wrote code, execute it and show me the real output.
- **Check the thing, not the step.** "The command ran without error" is not
  the same as "the result is correct". Look at the result.
- **Say what you checked.** "Tested with 3 inputs, all correct" beats
  "should be working now".
- **Say what you did NOT check.** If something could not be tested (needs a
  login, needs my phone), say so plainly instead of implying it works.
- **Numbers beat adjectives.** "Found 12 sources, 9 peer-reviewed" beats
  "found lots of good sources".
- **For anything visual** (a web page, a document), render it and look at it,
  or ask me to, before calling it finished.

## Why

AI models are very good at sounding confident. The fix is to make every
"done" come with evidence I can see.
